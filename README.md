# ヴォイスカウンター

車種調査などで、短い言葉を話して件数を集計する Android アプリです。Android 6.0 以降に対応します。

1. **集計開始**を押します。
2. **話してカウント**を押し、聞き取りが始まったら「トラック」など、ワードを一つ話します。初回はマイクを許可してください。
3. 新規ワードは 1 件で登録され、約 320 ミリ秒振動します。既存ワードは 1 件加算され、約 110 ミリ秒振動します。
4. 次のワードも、ボタンを押してから話します。
5. **集計終了**を押すと件数の多い順に横棒グラフを表示します。棒の右端は全件数です。**CSVを共有**から保存先または送信先を選びます。

集計は端末に 1 回分保存され、アプリを開き直しても再開できます。新しい集計の前に必要な CSV を保存してください。CSV は UTF-8（BOM 付き）で「ワード」「カウント」を登録順で出力します。

端末の日本語音声認識サービスを使います。サービスによっては通信が必要です。アプリは音声ファイルを保存しません。

## APK

[GitHub Actions](https://github.com/mo201602-max/VoiceCounter/actions/workflows/android.yml) の成功した実行結果から `voice-counter-debug` をダウンロードします。ローカルでは JDK 17 と Android SDK 35 を用意し、`./gradlew assembleDebug` を実行します。
